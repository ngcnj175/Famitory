## 1.2 左下のバー（ゲーム全体の操作）

| ボタン | なにをする？ |
|---|---|
| **NEW**（新規） | 新しいゲームを作りはじめる |
| **OPEN**（読み込み） | 前に保存したゲームをひらく |
| **SAVE**（保存） | いま作っているゲームを保存する |
| **SHARE**（共有） | ゲームをURLにして人に送る／ARCADEにのせる |
| **JPN / ENG** | 日本語⇔英語の切り替え |

> **ワンポイント**
> 作ったゲームは、SAVEを押さないと消えてしまうことがあるよ。
> 作業の区切りごとにSAVEするのがおすすめ！

## 1.3 右下のバー（作るモードの切り替え）

ここで「今から何をするか」を切り替えるよ。
押すと、真ん中の作業スペースの中身がガラッと変わる。

| ボタン | なにをする場所？ |
|---|---|
| **PLAY**（プレイ） | 作ったゲームを実際に遊ぶ |
| **PIXEL**（ピクセル） | キャラクターや背景の **絵** をかく |
| **STAGE**（ステージ） | 床・敵・アイテムを **ならべる** |
| **BGM**（サウンド） | ゲームの **音楽と効果音** を作る |
| **ARCADE** | みんなが公開したゲームを **見る・遊ぶ** |

今どのモードを使っているかは、ボタンの色でわかるよ。
（光っているボタンが「いま使っているモード」）

## 1.4 各モードの画面（ざっくり紹介）

くわしい使い方は次の章から説明するよ。ここでは「どんな場所か」だけ見てね。

### PIXEL画面

キャラや背景の **絵をかく** 場所。
左にはツール（ペン・消しゴムなど）、下には色えらびがあるよ。

> *スクリーンショット準備中*

### STAGE画面

ステージに **ブロックや敵をならべる** 場所。
右側に「使えるパーツ一覧」があるので、そこから選んで配置するよ。

> *スクリーンショット準備中*

### BGM画面

**音楽と効果音** を作る場所。
音符をマス目に置くイメージで曲が作れるよ。

> *スクリーンショット準備中*

### PLAY画面

作ったゲームを **実際に遊ぶ** 場所。
キーボードやスマホの画面ボタンで操作するよ。

> *スクリーンショット準備中*

## 1.5 ゲーム設定（タイトル・名前）

PLAY画面の近くに、**ゲームのタイトル** や **作った人の名前** を入れる場所があるよ。
最初に設定しておくと、シェアするときに便利！

## まとめ

- ボタンは画面下のバーに全部ある
- **左下** ＝ ファイル操作、**右下** ＝ モード切り替え
- 作業する前に、まず右下のバーで「どのモードで作るか」を決めよう

次の章から、実際に **PIXEL（絵）** を触ってみよう！
