# 7. Play (PLAY)

Once your game is ready, try playing it yourself first.

## Give it a try

On the PLAY screen, press the **START** button to actually play the game you made.

| Button | Key | Action |
|:---:|---|---|
| **Up** | W / ↑ | Move up |
| **Down** | S / ↓ | Move down |
| **Left** | A / ← | Move left |
| **Right** | D / → | Move right |
| **A** | Space / Z / J | Jump |
| **B** | X / K | Attack |
| **START** | Enter | Start / Pause (long-press to restart) |
