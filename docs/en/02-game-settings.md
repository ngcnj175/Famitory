# 3. First Steps (NEW)

## How to begin

Let's start making a game! There are two ways to begin.

### Start from scratch

Press the **NEW** button on the bottom-left bar to start building your own game from zero.
You can also start a new game from the screen that appears after playing another game.

### Remix an existing game

On the screen that appears after playing someone else's game, press **"Remix this game"** to use the original as a base and freely rearrange it.

!> You can only remix games whose creator marked them as "Allow Remix."
