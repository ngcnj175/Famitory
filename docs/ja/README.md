## FAMITORY（ファミトリー） とは？

ブラウザで動くレトロゲームメーカーです。

## どんなことができる？

- ドット絵でキャラクターや背景をかける
- ブロックや敵を置いて、オリジナルのステージが作れる
- BGMや効果音も自分で作れる
- 作ったゲームをURLで友達に送れる

## 動く環境

PC・スマホ・タブレット、どれでも遊べて、どれでも作れます。

## 使い方のヒント

- 左サイドバーの目次から、好きな章にジャンプできます
- 画面上の **検索ボックス** でキーワード検索ができます（例：「保存」「敵」など）
- スマホ・タブレットでも読めます

まずは左サイドバーの **「画面とボタンの見方」** から読んでみよう！
