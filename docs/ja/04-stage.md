# 5. ステージをつくる（STAGE）

STAGE は、PIXEL でかいたキャラクターやブロック・背景を配置して、ゲームの舞台（ステージ）を作る画面だよ。

<ul style="list-style:none; padding-left:0;">
<li>❶ <strong>タイルパレット</strong> … ステージに置けるタイルの一覧。</li>
<li>❷ <strong>タイル設定</strong> … えらんだタイルの中身や動きを決めるところ。</li>
<li>❸ <strong>ツールバー</strong> … 配置・けしごむなどの道具。</li>
<li>❹ <strong>キャンバス</strong> … ここにタイルを置いてステージを作るよ。</li>
<li>❺ <strong>ゲーム設定</strong> … ステージの大きさ・BGM・効果音などをまとめて設定。</li>
</ul>

---

## タイルパレットの使い方

タイルパレットは、ステージに置ける部品（タイル）の一覧だよ。

- **タイルをえらぶ** … タップするとえらべるよ。
- **タイル設定をひらく** … えらんだタイルをもう一度タップすると、タイル設定がひらくよ。
- **新しいタイルを追加** … `＋` を押すと、新しいタイルを追加できるよ。
- **タイルの種類** … タイルには **プレイヤー**・**てき**・**ブロック／背景**・**アイテム** の4種類があるよ。
- **複製・削除** … タイルを長押しすると、**複製** か **削除** をえらべるよ。

---

## タイル設定の使い方

タイル設定では、えらんだタイルの絵や動き・パラメータを決められるよ。

- **スプライト** … タイルで使う絵（PIXELで作ったもの）をわりあてるよ。
- **アニメーション** … 歩き・ジャンプなど、動きごとに使うコマを設定できるよ。
- **パラメータ** … 体力・スピード・攻撃力など、タイルの種類に合わせた細かい設定ができるよ。
- 変更したら上の **保存** を押して確定してね。

## キャンバスの使い方

キャンバスは、タイルを置いてステージを組み立てるエリアだよ。

- タイルパレットでえらんだタイルを、画面でなぞると置けるよ。
- まちがえたら **取り消し** でもどしたり、**消しゴム** で消したりしよう。
- **ハンドツール** を使うと、キャンバスをつまんで見る場所を動かせるよ。（2本指でなぞってもOK）

---

## ゲーム設定の使い方

画面上の **▼ ゲーム設定** を押すとひらくよ。ステージ全体のルールや音をまとめて決められるよ。

- **ステージサイズ** … 縦・横のマス数を変えられるよ。
- **背景色** … ステージの背景の色を変えられるよ。
- **クリア条件** … なし・アイテム取得・敵ぜんめつ・ボス撃破・サバイバルからえらべるよ。
- **制限時間** … 分・秒で時間制限を設定できるよ（0なら無制限）。
- **スコア表示** … プレイ中のスコア表示をオン/オフできるよ。
- **BGM** … ステージ・無敵・クリア・ゲームオーバー・ボスのBGMをえらべるよ。
- **効果音** … プレイヤー・アイテム取得・環境ごとに効果音をえらべるよ。
