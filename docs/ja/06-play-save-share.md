# 7. 遊ぶ・保存・シェアする

ゲームができたら、まずは自分で遊んでみよう。
うまくできていたら、保存して友達にシェアしてみよう！

---

## PLAYで遊んでみる

画面下の **PLAY** ボタンを押すと、作ったゲームを実際に遊べるよ。

<img src="assets/screenshots/PLAY画面.png" alt="PLAY画面" style="max-width:50%; min-width:260px; border:1px solid #ddd; border-radius:4px; box-shadow:0 1px 4px rgba(0,0,0,0.1); display:block; margin:16px 0;">

- **STARTボタン** を押すとゲームスタート
- **パソコン** は矢印キー・Spaceキーで操作
- **スマホ・タブレット** は画面の十字キー・A/Bボタン・STARTボタンをタップ
- クリアやゲームオーバーで結果画面が出る。もう一度あそぶなら STARTボタンをもう一度

?> 少し作っては PLAY で動かしてみる、を繰り返すのがおすすめ。<br>あとからまとめて直すより、こまめに確認したほうがラクだよ。

---

## SAVEで自分のパソコンに保存する

作ったゲームは **SAVE** ボタンで保存しないと消えてしまうことがあるよ。
作業の区切りごとに保存しよう。

<img src="assets/screenshots/SAVEモーダル.png" alt="SAVEモーダル" style="max-width:50%; min-width:260px; border:1px solid #ddd; border-radius:4px; box-shadow:0 1px 4px rgba(0,0,0,0.1); display:block; margin:16px 0;">

| ボタン | なにをする？ |
|---|---|
| **ゲームデータ名を入力 → 保存** | 名前をつけて自分のパソコンに保存。同じ名前なら上書き保存 |
| **エクスポート** | ゲームをファイルとして書き出せる。別のパソコンに持っていくときに使う |

?> **SAVE と「公開（SHARE）」はまったく別物。**<br>SAVE は自分のパソコンの中に残すだけ、SHARE は世界中にURLで公開するよ。

---

## SHAREでURLをつくって共有する

**SHARE** ボタンを押すと、ゲームを公開してURLを作れるよ。
そのURLを友達に送れば、誰でもあなたのゲームを遊べる！

<img src="assets/screenshots/SHAREモーダル.png" alt="SHAREモーダル" style="max-width:50%; min-width:260px; border:1px solid #ddd; border-radius:4px; box-shadow:0 1px 4px rgba(0,0,0,0.1); display:block; margin:16px 0;">

### はじめて公開する

公開のまえに、**タイトルとクリエイター名** が入っているか確認しよう（第3章参照）。

1. **SHARE** ボタンを押す
2. モーダルの一番下にある **「ゲームを公開する」** ボタンを押す
3. 「この作品を公開しますか？」と聞かれるので **はい** を押す
4. 公開完了！

公開が終わると、**エディットキー** という8桁の合言葉が発行されるよ。

<img src="assets/screenshots/エディットキーアラート.png" alt="エディットキーアラート" style="max-width:50%; min-width:260px; border:1px solid #ddd; border-radius:4px; box-shadow:0 1px 4px rgba(0,0,0,0.1); display:block; margin:16px 0;">

!> **【超重要】エディットキーをメモしよう**<br>エディットキーは、ゲームごとに1つだけの合言葉。<br>**別のパソコンから自分のゲームを編集するとき** に必要になるよ。<br>ダイアログに表示されたキーをメモ帳やスマホのメモにコピーして、なくさないように保存しておこう。<br>（もし忘れても、SHAREモーダルを開けばいつでも確認できるよ）

### URLで友達にシェアする

公開が終わると、SHAREモーダルに **「共有する」** ボタンが出てくるよ。
押すと共有メニューが開く。

| ボタン | なにをする？ |
|---|---|
| **URLをコピー** | URLをクリップボードにコピー。LINE・メール・DMに貼りつけて送れる |
| **Xに投稿** | X（旧Twitter）の投稿画面を開く |
| **Discordに投稿** | Discordの投稿画面を開く |

渡されたURLを開くだけで、相手は何もインストールせずあなたのゲームを遊べるよ。

### ARCADEにのせてみんなに見てもらう

SHAREモーダルの **「アーケードに登録」** にチェックを入れると、ARCADE画面の公開ギャラリーに自分のゲームが並ぶよ。
知らない人にも遊んでもらえるチャンス！

- **コメント** … ゲームの短い紹介文
- **サムネイル** … ARCADE一覧に表示される小さな画像。**「プレイ画面から取得」** ボタンでPLAY中の画面をキャプチャできる（先に一度PLAYで動かしておく必要あり）
- **リミックスOK** … チェックすると、他の人があなたのゲームをもとに自由にアレンジできるようになる

### 公開した作品を更新する

公開したあとでバグに気づいたり、もっとよくしたくなったら、普通に編集して保存しなおせばいいよ。

1. PIXEL / STAGE / BGM で中身を直す
2. **SAVE** で保存
3. **SHARE** ボタン → **「ゲームを更新する」** ボタンを押す
4. 確認ダイアログで **はい**

?> **URLは変わらない**ので、友達が前にもらったURLをもう一度開けば最新バージョンがあそべるよ。

### 一時的に非公開にする／再公開する

「もう公開したくない」「大きく作り直したいから一度隠したい」というときは、SHAREモーダル右上の **「非公開にする」** を押そう。

- だれもアクセスできなくなる（URLを開いても「見つかりません」になる）
- **再公開するといつでも同じURLに戻せる**
- **いいね数やハイスコアもそのまま残る**

再び公開したいときは、SHAREモーダルを開いて **「ゲームを公開する」** を押すだけ。前と同じURLで復活するので、SNSで共有済みのリンクもそのまま使えるよ。

?> こんなときに便利！<br>・SNSでゲームを広めたあとに不具合が見つかって、修正中は一時的に隠したい<br>・大きく作り変えたいから、しばらく下書き状態にしたい

### 別の端末から編集するとき

自分の公開URLを **別のパソコン** や **ふだんと違うブラウザ** で開くと、最初は「プレイヤーモード」（遊ぶだけの状態）で開くよ。

編集用のボタン（PIXEL / STAGE / BGM / SAVE / SHARE / ARCADE）はグレーになっていて、押すと **エディットキーの入力モーダル** が出てくる。

控えておいた8桁のキーを入力して **認証** を押すと、作者モードに戻って編集や更新・非公開ができるよ。

!> キーを忘れたら？<br>元のパソコン・ブラウザでSHAREモーダルを開けば、いつでもエディットキーを確認できるよ。<br>大切なゲームのキーは、作ったときに必ず控える習慣をつけよう。

---

## まとめ

- **PLAY** で遊ぶ、**SAVE** で保存、**SHARE** で公開
- 公開のときに出る **エディットキーは必ず控える**（なくすと別端末から編集できなくなる）
- 公開後は何度でも **更新・非公開・再公開** できる
- 非公開にしてもURL・いいね・ハイスコアは残るので、安心して試せる
