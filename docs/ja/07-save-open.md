# 8. 保存・開く（SAVE・OPEN）

作ったゲームは保存しておけば、あとから続きを編集したり、ほかのスマホに持っていったりできるよ。

## 保存する

作ったゲームは **SAVE** ボタンでブラウザ内に保存されるよ。作業の区切りごとに保存しよう。

**エクスポート**<br>
ゲームをファイルとして書き出せるよ。別のスマホに持っていきたいときや、バックアップを取っておきたいときに使おう。

!> ブラウザの履歴を消したり、しばらく使わなかったりするとSAVEデータは消えてしまうことがあるので、大事に残したいゲームは、**エクスポートでファイルに書き出すか、SHAREで公開しておこう！**

---

## 開く

**OPEN** ボタンを押して、SAVEで保存したゲーム一覧から、あそびたい・編集したいゲームをひらこう。

他にもこんなこともできるよ。

- **コピー** … そのゲームを複製する（元のゲームはそのまま残る）
- **けす** … そのゲームを完全に消す（取り消せないので注意！）

**インポート**<br>
エクスポートで書き出したファイルを読み込み、ゲーム一覧に追加できるよ。別のスマホで作ったゲームの続きを編集したいときや、バックアップから戻したいときに使おう。
