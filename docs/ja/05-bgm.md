# 6. 音をつける（BGM）

BGM は、ゲームの中で流れる音楽（BGM）を作る画面だよ。BGMを作って、ゲーム設定でステージ・クリア・ゲームオーバーなどの場面にわりあてよう。

<ul style="list-style:none; padding-left:0;">
<li>❶ <strong>ソングバー</strong> … BGMをえらんだり、テンポや長さを決めるところ。</li>
<li>❷ <strong>トラックパネル</strong> … 4つの音色・音量・パンを決めるところ。</li>
<li>❸ <strong>キャンバス</strong> … 音をならべてBGMを作るエリア。</li>
<li>❹ <strong>ツールバー</strong> … 音を置く・消すなどの道具。</li>
<li>❺ <strong>鍵盤</strong> … 音を鳴らしながら入力するけんばん。</li>
<li>❻ <strong>プレイバー</strong> … 再生・録音・位置の移動などをするところ。</li>
</ul>

---

## ソングバーの使い方

ソングバーは、BGMごとの設定をするところだよ。

- **BGMをえらぶ** … `⌄` でBGMをえらんで切りかえられるよ。
- **BGMの名前を変える** … BGM名をタップすると名前を変えられるよ。
- **新しいBGMを追加** … `＋` を押すと、新しいBGMを追加できるよ。
- **BGMを削除** … ごみばこボタンで、えらんでいるBGMを削除できるよ。
- **テンポ** … BGMの速さを決めるよ。数字を上下にドラッグしたり、タップして直接数字を入れて変えてね。
- **ステップ数** … BGMの長さ（マスの数）を決めるよ。数字を上下にドラッグしたり、タップして直接数字を入れて変えてね。

---

## トラックパネルの使い方

トラックパネルでは、音色や音量を決められるよ。
ファミコンにならって、次の4つのトラックで作るよ。

- **矩形波** … メロディによく使われるトラック。（2つあるよ）
- **三角波** … ベース（低い音）に向いているトラック。
- **ノイズ** … ドラムなどのリズムに向いているトラック。

<br>

- **音色をえらぶ** … 長押しでトラックごとに使う音色をえらべるよ。
- **音量** … つまみを動かして、トラックごとの大きさを変えられるよ。
- **パン** … 左右どちら側から音を出すかを決められるよ。
- **ミュート** … えらんだトラックをもう一度タップすると、そのトラックの音を消せるよ。

---

## キャンバスの使い方

キャンバスは、音をならべてBGMを作るエリアだよ。たて軸が音の高さ（ピッチ）、よこ軸が時間（ステップ）になっているよ。

- **音を置く** … マスをタップすると、その位置に音を置けるよ。
- **音の長さをのばす** … 音の右はしをドラッグすると、長さを変えられるよ。
- **音を消す** … 消しゴムに切りかえてタップすると消せるよ。
- **トラックの切りかえ** … 編集中のトラックは、トラックパネルで切りかえられるよ。

## 鍵盤の使い方

画面下の鍵盤を使うと、音を鳴らしながらBGMを入力できるよ。

- **音をならす** … けんばんをタップすると、えらんでいるトラックの音色で音が鳴るよ。
- **音のたかさを変える** … 鍵盤の上にあるスクロールバーでひくい音・たかい音にうつれるよ。
- **録音する** … RECボタンをオンにすると、その音がキャンバスに記録されるよ。（再生中なら実際のえんそう、停止中なら1音ずつ進む）

---

## プレイバーの使い方

プレイバーには、再生や録音のためのボタンがならんでいるよ。

- **戻る** … 再生位置を1ステップ前にもどすよ。ステップ録音でまちがえたときに便利。
- **REST（休符）** … いまの位置に休み（音なし）を入れて、1ステップ進むよ。
- **TIE（タイ）** … いまの位置の音を1ステップのばすよ。長い音を入れるのに便利。
- **メトロノーム** … オンにすると、再生・録音のあいだ拍子に合わせて音が鳴るよ。
- **STEP REC** … ステップ録音のオン/オフを切りかえるよ。オンのあいだは、鍵盤でおした音がキャンバスに記録されて、1ステップずつ進むよ。
- **PLAY / STOP** … BGMを再生・停止するよ。

---

## 作ったBGMをゲームで使うには

作ったBGMは、STAGE 画面の **ゲーム設定 → BGM** でわりあてると、ゲームの中で流れるよ。

- **ステージ** … ふだんのプレイ中に流れるBGM。
- **無敵** … むてき状態のときに流れるBGM。
- **クリア** … ステージをクリアしたときに流れるBGM。
- **ゲームオーバー** … ゲームオーバーのときに流れるBGM。
- **ボス** … ボスとたたかうときに流れるBGM。
