# 6. 音をつける（BGM）

BGM は、ゲームの中で流れる音楽（BGM）を作る画面だよ。曲を作って、ゲーム設定でステージ・クリア・ゲームオーバーなどの場面にわりあてよう。

<ul style="list-style:none; padding-left:0;">
<li>❶ <strong>ソングバー</strong> … 曲をえらんだり、テンポや長さを決めるところ。</li>
<li>❷ <strong>トラックパネル</strong> … 4つの音色・音量・パンを決めるところ。</li>
<li>❸ <strong>キャンバス</strong> … 音をならべて曲を作るエリア。</li>
<li>❹ <strong>ツールバー</strong> … 音を置く・消すなどの道具。</li>
<li>❺ <strong>鍵盤</strong> … 音を鳴らしながら入力するけんばん。</li>
<li>❻ <strong>プレイバー</strong> … 再生・録音・位置の移動などをするところ。</li>
</ul>

---

## ソングバーの使い方

ソングバーは、曲ぜんたいの設定をするところだよ。

- **曲をえらぶ** … `〈` `〉` で前後の曲に切りかえられるよ。
- **曲の名前を変える** … 曲名をタップすると名前を変えられるよ。
- **新しい曲を追加** … `＋` を押すと、新しい曲を追加できるよ。
- **曲を削除** … ごみばこボタンで、えらんでいる曲を削除できるよ。
- **テンポ** … 曲の速さを決めるよ。数字を上下にドラッグして変えてね。
- **ステップ数** … 曲の長さ（マスの数）を決めるよ。数字を上下にドラッグして変えてね。

---

## トラックパネルの使い方

トラックパネルでは、4つのトラック（声のパート）の音色や音量を決められるよ。

- **音色をえらぶ** … トラックごとに、使う音色をえらべるよ。
- **音量** … つまみを動かして、トラックごとの大きさを変えられるよ。
- **パン** … 左右どちら側から音を出すかを決められるよ。
- **ミュート** … 一時的にそのトラックの音を消せるよ。

---

## キャンバスの使い方

キャンバスは、音をならべて曲を作るエリアだよ。たて軸が音の高さ（ピッチ）、よこ軸が時間（ステップ）になっているよ。

- **音を置く** … マスをタップすると、その位置に音を置けるよ。
- **音の長さをのばす** … 音の右はしをドラッグすると、長さを変えられるよ。
- **音を消す** … 消しゴムに切りかえてタップすると消せるよ。
- **トラックの切りかえ** … 編集中のトラックは、トラックパネルで切りかえられるよ。

---

## 鍵盤の使い方

画面下の鍵盤を使うと、音を鳴らしながら曲を入力できるよ。

- **音をならす** … けんばんをタップすると、えらんでいるトラックの音色で音が鳴るよ。
- **ステップ録音** … プレイバーの **STEP REC** をオンにしてから鍵盤を押すと、その音がキャンバスに記録されて、位置がひとつ進むよ。
- **音のたかさを変える** … 左右にスクロールすると、ひくい音・たかい音にうつれるよ。

---

## プレイバーの使い方

プレイバーには、再生や録音のためのボタンがならんでいるよ。

- **PLAY / STOP** … 曲を再生・停止するよ。
- **STEP REC** … ステップ録音のオン/オフを切りかえるよ。オンのあいだは、鍵盤でおした音がキャンバスに記録されるよ。
- **再生位置の移動** … 1ステップずつ前・後ろに動かせるよ。ステップ録音でまちがえたときにもどせるよ。
- **音をのばす** … いまの位置の音を1ステップのばせるよ。長い音を入れるのに便利だよ。
- **メトロノーム** … オンにすると、再生・録音のあいだ拍子に合わせて音が鳴るよ。

---

## 作った曲をゲームで使うには

作った曲は、STAGE 画面の **ゲーム設定 → BGM** でわりあてると、ゲームの中で流れるよ。

- **ステージ** … ふだんのプレイ中に流れる曲。
- **無敵** … むてき状態のときに流れる曲。
- **クリア** … ステージをクリアしたときに流れる曲。
- **ゲームオーバー** … ゲームオーバーのときに流れる曲。
- **ボス** … ボスとたたかうときに流れる曲。
