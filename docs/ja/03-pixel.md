# 3. 絵をかく（PIXEL）

PIXEL は、ゲームに出てくるキャラクターやブロック、背景などの絵をかく画面だよ。

**画面の見方**

1. **プレビュー** … 絵の動きを確認できるよ。
2. **ピクセルパレット** … 作った絵の一覧。
3. **ツールバー** … えんぴつ・けしごむなどの道具。
4. **キャンバス** … ここに絵をかくよ。
5. **カラーパレット** … 使う色をえらぶところ。

---

## プレビューの使い方

プレビューは、かいた絵を**動かして確認**できるところだよ。

- **ひらく／とじる** … プレビューバーをタップすると、ひらいたりとじたりできるよ。
- **絵をならべる** … 下のピクセルパレットから、動かしたい絵をドラッグ＆ドロップでプレビューに入れよう。
- **動きを見る** … 複数の絵をならべて `▶` を押すと、ならべた順にパラパラと動いて見えるよ。
- **スピードを変える** … スピードゲージで、動きの速さを調節できるよ。
- **タイルモード** … オンにすると、絵をタイルのようにならべて表示して、**ピクセルの繋がり**（背景やブロックが自然につながるか）を確認できるよ。

---

## ピクセルパレットの使い方

ピクセルパレットは、作った絵の一覧だよ。ここで絵をえらんだり、新しい絵を追加したりできるよ。

- **新しい絵を追加** … `＋` を押すと、新しいピクセルを追加できるよ。
- **削除・複製** … 絵を長押しすると、**削除** または **複製** をえらべるよ。
- **サイズを2倍にする** … 絵をダブルタップすると、ピクセルサイズを **2倍（32×32）** に切りかえられるよ。
