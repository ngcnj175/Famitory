# 3. 絵をかく（PIXEL）

**PIXEL** は、ゲームに出てくるキャラクターやブロック、背景などの絵をかく画面だよ。
下のメニューで **PIXEL** を押すと、この画面になるよ。

---

## 画面の見方

- **プレビュー**（いちばん上）… かいている絵の動きを確認できるよ。
- **ギャラリー**（上の横ならび）… これまでに作った絵の一覧。えらんで切りかえよう。`＋` で新しい絵を追加できるよ。
- **キャンバス**（まんなかの大きなマス目）… ここに絵をかくよ。
- **ツールバー**（左のたて並び）… えんぴつ・けしごむなどの道具。
- **カラーパレット**（いちばん下）… 使う色をえらぶところ。`＋` で色を追加できるよ。

---

## ツールバーの使い方

| 道具 | はたらき |
|---|---|
| えんぴつ | 今えらんでいる色でマスをぬる |
| けしごむ | マスを消す（とうめいにする） |
| ぬりつぶし | つながっている同じ色をいっぺんにぬる |
| スポイト | キャンバスの色をえらんで、使う色にする |
| もどす（Undo） | ひとつ前の操作にもどす |
| 選択 | 一部分だけえらんで動かしたりコピーしたりする |
| コピー | 今の絵を別のコマにコピーする |

---

## 絵をかく流れ

1. **ギャラリー** で絵をえらぶ（または `＋` で新しく作る）。
2. **カラーパレット** で使う色をえらぶ。
3. **えんぴつ** でキャンバスにぬっていく。
4. まちがえたら **けしごむ** か **もどす** でなおす。
5. **プレビュー** で動きを確認する。

---

## 色をふやしたいとき

カラーパレットの左にある `＋` を押すと、新しい色を追加できるよ。
色をおし続けると、色を変えたり消したりもできるよ。
