# 3. 絵をかく（PIXEL）

PIXEL は、ゲームに出てくるキャラクターやブロック、背景などの絵をかく画面だよ。

<img src="assets/screenshots/PIXEL画面.png" alt="PIXEL画面" style="max-width:50%; min-width:260px; border:1px solid #ddd; border-radius:4px; box-shadow:0 1px 4px rgba(0,0,0,0.1); display:block; margin:16px 0;">

**画面の見方**

1. **プレビュー** … 絵の動きを確認できるよ。
2. **ピクセルパレット** … 作った絵の一覧。
3. **ツールバー** … えんぴつ・けしごむなどの道具。
4. **キャンバス** … ここに絵をかくよ。
5. **カラーパレット** … 使う色をえらぶところ。

---

## プレビューの使い方

プレビューは、かいた絵を**動かして確認**できるところだよ。

- **ひらく／とじる** … プレビューバーをタップすると、ひらいたりとじたりできるよ。
- **絵をならべる** … 下のピクセルパレットから、動かしたい絵をドラッグ＆ドロップでプレビューに入れよう。
- **動きを見る** … 複数の絵をならべて `▶` を押すと、ならべた順にパラパラと動いて見えるよ。
- **スピードを変える** … スピードゲージで、動きの速さを調節できるよ。
- **タイルモード** … オンにすると、絵をタイルのようにならべて表示して、**ピクセルの繋がり**（背景やブロックが自然につながるか）を確認できるよ。

---

## ピクセルパレットの使い方

ピクセルパレットは、作った絵の一覧だよ。ここで絵をえらんだり、新しい絵を追加したりできるよ。

- **新しい絵を追加** … `＋` を押すと、新しいピクセルを追加できるよ。
- **削除・複製** … 絵を長押しすると、**削除** または **複製** をえらべるよ。
- **サイズを2倍にする** … 絵をダブルタップすると、ピクセルサイズを **2倍（32×32）** に切りかえられるよ。

---

## キャンバスの使い方

キャンバスは、絵をかくマス目のエリアだよ。

- 画面を指でなぞると、えらんだ道具で絵をかけるよ。
- まちがえたら **取り消し** でもどしたり、**消しゴム** で消したりしよう。
- **ハンド** を使うと、キャンバスをずらして見る場所を動かせるよ。

---

## カラーパレットの使い方

カラーパレットは、キャンバスで使う色をえらぶところだよ。

- **色をえらぶ** … 使いたい色をタップするとえらべるよ。
- **色を追加** … 左の `＋` を押すと、新しい色を追加できるよ。
- **色の編集・削除** … 色を長押しすると、**色を変える** か **削除する** かをえらべるよ。
