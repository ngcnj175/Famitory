# 3. 作りはじめ（NEW）

## はじめ方

さっそくゲームを作りはじめよう！はじめ方は2つあるよ。

### ＜あたらしく作る＞

左下バーの **NEW** ボタンをタップするとゼロから自分のゲームを作りはじめられるよ。
他のゲームを遊んだあとの画面からもはじめられるよ。

### ＜リミックスする＞

他のゲームを遊んだあとの画面に出てくる **「このゲームをリミックスする」** ボタンからはじめられるよ。元のゲームを土台にして自由にアレンジできるよ。

?> リミックスできるのは、元の作者が「リミックスOK」にしている作品だけだよ。

## ゲーム情報

### タイトル

ゲームの名前。PLAY画面の上に表示されたり、シェアするときに他の人の目にふれる名前になるよ。

### 作った人の名前

このゲームを作った人の名前。あとで公開するときに「だれが作ったか」として表示されるよ。
