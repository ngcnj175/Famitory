# ＜第2章＞ ゲーム情報を決めよう

ゲームを作りはじめる前に、まず **タイトル**・**作った人の名前**・**エディットキー** を決めよう。
最初に設定しておくと、保存やシェアのときに便利！

> *スクリーンショット準備中*

---

## タイトル

ゲームの名前。PLAY画面の上に表示されたり、シェアするときに他の人の目にふれる名前になるよ。

## 作った人の名前

このゲームを作った人の名前。あとで公開するときに「だれが作ったか」として表示されるよ。

## エディットキー

自分のゲームを他の人に書きかえられないようにする、合い言葉のようなもの。
忘れないようにメモしておこう！
