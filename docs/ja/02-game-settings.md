# 3. 作りはじめ（NEW）

## はじめ方

まずはゲームを新しく始めよう。方法は2つあるよ。

### ＜あたらしく作る＞

左下バーの **NEW** ボタンをタップすると、ゼロから自分のゲームを作りはじめられるよ。
他の人のゲームを遊んだあとの画面に出てくるボタンからも始められる。

### ＜リミックスする＞

他の人のゲームを遊んだあとの画面に出てくる **「このゲームをリミックスする」** ボタンから、元のゲームを土台にして自由にアレンジできるよ。

?> リミックスできるのは、元の作者が「リミックスOK」にしている作品だけだよ。

## ゲーム情報

### タイトル

ゲームの名前。PLAY画面の上に表示されたり、シェアするときに他の人の目にふれる名前になるよ。

### 作った人の名前

このゲームを作った人の名前。あとで公開するときに「だれが作ったか」として表示されるよ。
