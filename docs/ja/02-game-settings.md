# 3. ゲームを作る（NEW）

まずはゲームを新しく始めよう。方法は2つあるよ。

## あたらしく作る〈NEW〉

タイトル画面の **NEW** ボタンを押すと、ゼロから自分のゲームを作りはじめられるよ。

## リミックスする〈REMIX〉

ARCADEや他の人のゲームURLで **「このゲームをリミックスする」** を押すと、元のゲームを土台にして自由にアレンジできるよ。

?> リミックスできるのは、元の作者が「リミックスOK」にしている作品だけだよ。

---

ゲームを作りはじめたら、まず **タイトル** と **作った人の名前** を決めよう。
最初に設定しておくと、保存やシェアするときに便利！

## タイトル

ゲームの名前。PLAY画面の上に表示されたり、シェアするときに他の人の目にふれる名前になるよ。

## 作った人の名前

このゲームを作った人の名前。あとで公開するときに「だれが作ったか」として表示されるよ。
