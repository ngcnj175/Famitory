# 3. 作りはじめ（NEW）

## はじめ方

さっそくゲームを作りはじめよう！はじめ方は2つあるよ。

### ＜あたらしく作る＞

左下バーの **NEW** ボタンをタップするとゼロから自分のゲームを作りはじめられるよ。
他のゲームを遊んだあとの画面からもはじめられるよ。

### ＜リミックスする＞

他のゲームを遊んだあとの画面に出てくる **「このゲームをリミックスする」** ボタンをタップすると、元のゲームを土台にして自由にアレンジできるよ。

?> リミックスできるのは、元の作者が「リミックスOK」にしている作品だけだよ。

## ゲーム情報

まずはタイトルとクリエーター名を決めるよ。最初に決めてもいいし、あとでPLAY画面から変えることもできるよ。

### ＜ゲームタイトル＞

ゲームの名前。

### ＜クリエーター＞

このゲームを作った人の名前。つまりキミの事だね。
